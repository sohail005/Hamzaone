# HamzaOne design handoff

These are the design source files exported from Claude Design.
Each `*.dc.html` file is one screen. Markup and inline styles are the visual spec.
The `<script type="text/x-dc">` block at the bottom of each file holds sample data and UI behaviour.
`canvas.json` lists every screen, its section and its width.

Start with:
- `Artboard-nmho.dc.html` (project overview)
- `Sitemap.dc.html` (pages and journeys)
- `DesignSystem.dc.html` (colours, type, components)
- `Handoff.dc.html` (developer notes)

Fonts: Inter (body) and Manrope (headings) from Google Fonts.
Note: `support.js` is the design tool runtime and is not part of the website.
